|---|---|---|
| Correcteur de calcul posé (ceintures Charivari) | https://xaviergougaud1-netizen.github.io/outils-classe/correcteur/ | 1.0.0 |

## Mettre à jour un outil
- Changer `VERSION` dans `index.html` **et** `CACHE` dans `sw.js` (sinon les téléphones gardent l'ancienne version).
- Ajouter une ligne dans « Nouveautés ».
